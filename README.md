## 🌟 About CampusSafe

CampusSafe is a modern, real-time emergency communication system built
to ensure safety within campus environments. It empowers administrators
to instantly broadcast alerts during critical situations such as fire,
medical emergencies, or security threats, ensuring rapid awareness and
coordinated response.

------------------------------------------------------------------------

## ✨ Core Features

-   🚨 Instant Emergency Alert System\
-   📍 Location-Based Reporting\
-   🔴 Full-Screen Alert Interface\
-   📢 Safety Instructions\
-   📳 Vibration & Alarm System\
-   ✅ Status Reporting (Safe / Help)\
-   📞 Emergency Call\
-   📧 Email Integration

------------------------------------------------------------------------

## 🧠 System Architecture

Admin Panel → AlertManager → Foreground Service → Broadcast → Student
