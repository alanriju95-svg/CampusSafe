## 📖 Overview

CampusSafe is an intelligent campus monitoring and safety system designed to enhance security, automate monitoring, and provide real-time information to administrators, faculty, and students.

The system integrates IoT devices, cloud connectivity, and a modern web dashboard to continuously monitor environmental conditions and campus activities while generating instant alerts whenever abnormal situations are detected.
